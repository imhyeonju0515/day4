# 서귀포 관광지 관람객 추이

서귀포시 직영관광지 6곳(천지연폭포·천제연폭포·정방폭포·중문대포 주상절리대·산방산 용머리·감귤박물관)의 **월별 관람객 수**를 3D 제주 디오라마(Three.js)와 차트(Chart.js)로 보여 주는 사이트예요. 기둥이 높고 붉을수록 사람이 많은 달이고, 아래 차트에서 "언제 가면 한적한지" 알려 줘요.

- 데이터: 공공데이터포털 「제주특별자치도 서귀포시_직영관광지 관람객수 추이」(OpenAPI, JSON) — 출처 표기 포함
- 화면: 기간 슬라이더/▶ 재생, 기둥 클릭(그 관광지만 보기), 관광지 칩, 월별 추이 차트, 붐비는 달·한적한 달
- `주소 끝에 ?demo=1` 을 붙이면 가짜 샘플 데이터로 화면만 미리 볼 수 있어요(인증키 없이)

## 환경변수 1개

| 이름 | 어디서 얻나 | 노출 |
|---|---|---|
| `DATA_GO_KR_KEY` | data.go.kr → 마이페이지 → 개발계정 → 이 API의 **일반 인증키** (Decoding 권장, Encoding 도 자동 처리) | 서버 전용 (`VITE_` 붙이지 않기) |

## 설정 순서
1. 공공데이터포털에서 위 데이터의 **활용신청**(자동 승인)을 하고 인증키를 확인해요.
2. **로컬 실행:** `.env.example` 을 `.env` 로 복사해 키를 넣고
   ```bash
   npm install
   npm run dev
   ```
3. **Vercel 배포:** Add New Project → 저장소 선택 → **Root Directory 를 `seogwipo-tour`** 로 지정 → Environment Variables 에 `DATA_GO_KR_KEY` 를 **secret** 으로 등록 → Deploy.
4. 키를 등록한 직후에는 승인 반영에 1~2시간 걸릴 수 있어요. 화면에 "불러오지 못했어요"가 뜨면 잠시 뒤 다시 확인해 주세요.

## 구조
- `api/visitors.js` odcloud API 를 서버에서 호출(최대 5페이지, 24시간 캐시), 숫자/빈 값 정리 → `{ spots, rows:[{y,m,v[]}], updated }`
- `src/diorama.js` Three.js 3D 섬 + 관광지 기둥(높이·색 = 관람객 수), 클릭/회전
- `src/charts.js` Chart.js 추이 선 그래프(현재 달 표시선), 월별 평균 막대(붐빔/한적 색)
- `src/main.js` 상태 관리(선택한 관광지, 기간 슬라이더, 재생)
- `src/data.js` 데이터 불러오기와 `?demo=1` 샘플

## 데이터 메모
- 데이터셋: `15125100`, 이 사이트는 `20251002` 버전(uddi:32a1b877-…)을 써요. 칼럼: 기준연도, 기준월, 6개 관광지, 데이터기준일자.
- "공란사유: 데이터 미집계" — 빈 달은 선이 끊기고 기둥에 "미집계"로 나와요.
